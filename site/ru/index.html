Один экранчик — много дел

MiniToo Studio общается с колонкой напрямую по Bluetooth RFCOMM и не даёт её экрану скучать: всё предсказуемое отправляется на минуту вперёд, и колонка проигрывает это сама.

Картинки и GIF

PNG, JPEG, GIF, WebP, APNG, SVG, JPEG XL и не только. Рамка кадрирования 5:4, режим пиксель-арта и локальная галерея с избранным.

Трансляция экрана

Выберите монитор или окно через портал рабочего стола и транслируйте его область до 20 кадров/с.

Живые режимы

Часы и погода, системный монитор, «Сейчас играет», Pomodoro, статистика Claude Code, GitHub Actions и визуализатор звука — по одному или ротацией.

Статус Claude Code

Работает, отдыхает или ждёт вас — с именем проекта и вопросом. 18 пиксельных анимаций и короткая мелодия при каждой смене.

Уведомления

Уведомления рабочего стола — карточками со значком отправителя поверх того, что на экране.

Блокировка экрана

Когда компьютер заблокирован, колонка показывает часы и приглушает яркость; после разблокировки всё возвращается как было.

Управление колонкой

Яркость, громкость, воспроизведение, включение экрана, синхронизация часов, заряд батареи, встроенные экраны и игры.

Автоматизация

Локальный HTTP API и командная строка: отправить картинку из скрипта, переключить режим, показать карточку об окончании сборки.

Русский и английский

24/12-часовой формат времени и форматы даты; переводы — обычные текстовые файлы, можно добавить свой язык.

Скриншоты

Интерфейс похож на саму колонку: пластиковые панели, клавиши с ходом, пиксельный текст — в бежевой и ночной темах.

Claude Code на вашем столе

Одна кнопка ставит хуки в ~/.claude/settings.json (с резервной копией и не трогая ваши остальные хуки). С этого момента колонка показывает, чем занят Claude, — и зовёт, когда нужны вы, с именем проекта и вопросом: «Разрешить Bash?».

18 сцен, нарисованных попиксельно на сетке 40×32, по шесть на каждое состояние — или свой GIF. Работающие субагенты тоже видны.

8-битные мелодии из самой колонки (если она подключена как аудио), на выбор из четырёх для каждого состояния.

Статистика: токены, сессии и лимиты подписки как живой режим, в шести видах.

Тревога может прерывать картинки и трансляцию, так что вопрос не останется незамеченным.

Установка

Понадобятся Divoom MiniToo и Bluetooth-адаптер. Сопряжение не нужно: при первом запуске откройте Настройки, введите MAC-адрес колонки или нажмите Найти.

Из релиза

Скачайте minitoo-studio-X.Y.Z-linux-x86_64.tar.gz со страницы Releases, затем:

tar xzf minitoo-studio-*-linux-x86_64.tar.gz
cd minitoo-studio-*-linux-x86_64
./minitoo-studio

…или из исходников

В контейнере, когда на хосте есть только Docker, — или локальным тулчейном (Rust 1.88+, заголовки PipeWire, clang, pkg-config):

./build.sh                 # → build/minitoo-studio
cargo build --release      # или без Docker

Меню приложений и автозапуск

Добавляет MiniToo Studio в меню приложений, а с --autostart — запускает его в трее при входе. Закрытое окно оставляет приложение работать в трее.

./packaging/install-desktop.sh --autostart   # --uninstall — убрать

Автоматизация

Приложение слушает 127.0.0.1:47800, только локально. То же самое доступно из командной строки.

ЗапросЧто делает
POST /showоткрыть файл и отправить
POST /notifyпоказать карточку уведомления
POST /live/<id>показать живой режим
POST /mode/<claude|idle>отдать экран Claude или освободить его
GET /statusсостояние Claude, сессии и субагенты
GET /frame/devicePNG того, что сейчас на колонке

Карточка, когда сборка закончилась:

curl -X POST -d '{"app":"build","summary":"Сборка готова","body":"0 ошибок"}' \
     http://127.0.0.1:47800/notify

Картинка из скрипта — через запущенное приложение:

minitoo-studio --send cat.gif --fit crop

Платформы
